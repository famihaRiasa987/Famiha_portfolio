# Famiha Riasa Portfolio

A clean, responsive personal portfolio website inspired by a minimal navy/mint developer aesthetic.

## Features

- Responsive single-page portfolio
- About, experience, projects, skills, education, and contact sections
- Interactive experience tabs
- Project carousel/cards
- Local profile photo and favicon
- Print-friendly resume page
- No framework or build step required

## Run locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Stack

HTML, CSS, and vanilla JavaScript.
